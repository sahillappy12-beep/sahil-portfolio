# Sample HTML Page

This repository contains a simple HTML page styled with CSS.  
It demonstrates the basics of structuring a webpage, applying styles, and creating interactive elements like buttons.

---

## 📄 Features
- Clean and minimal HTML structure
- Responsive design with `meta viewport`
- Styled container with shadow and rounded corners
- Custom button with hover effect
- Easy-to-read typography and layout

---

## 🖼️ Preview
The page includes:
- A **Welcome heading**
- A short **paragraph description**
- A styled **button** that can be linked to any action

## ✨ Customization
Change the background color in the body selector.

Update the button color in .btn and .btn:hover.

Replace the text inside <h1> and  with your own content.
